# MiTranslate

It is software for translating texts, listening to words and phrases and getting the meaning of words through the translate-shell.

## Information

 - [Repository MiTranslate](https://github.com/profmugomes/mitranslate)

## System Requirement

### Linux

- Ubuntu 26.04 or higher
- translate-shell
